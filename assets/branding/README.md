# AfricanBrowser artwork

The supplied africanbrowser-logo.png is the single source for every AfricanBrowser brand symbol, icon, picture, and emblem. Website and support extension icons use the same complete original artwork, including the wordmark and slogan.

scripts/logo_assets.py resizes this complete artwork for native browser product icons and Android launchers, retaining adaptive mask padding. Required tinted platform variants use grayscale.

Install a rebuilt APK to update the name and artwork on Android.
