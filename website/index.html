Chromium foundation

The project builds upstream Chromium with AfricanBrowser branding. Browser features depend on platform and build validation.

Open source

Inspect the code, review build instructions, and follow development. Original project code uses the BSD-3-Clause license.

Local support tooling

A separate local assistant and desktop extension are included in the source. They require their own setup and are not a hosted service on this website.

Questions & support

Is this a production-ready browser?

Not yet. The available Android APK is a development preview. Signing, runtime verification, update infrastructure, and platform release acceptance remain release work.

Where are desktop and iPhone downloads?

No compiled desktop or iPhone downloads are published here. Developers can follow the native build instructions. The initial iOS configuration targets the simulator.

How do I report a problem?

Open a GitHub issue with your platform, build version, and steps to reproduce. Remove passwords and private information from screenshots and logs.
